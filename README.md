WAVE_CLUST: Wavelet-based Analysis for Visualizing and Evaluating Clusters
WAVE_CLUST is a Python-based toolkit designed to analyze, visualize, and evaluate time-series or multi-frequency clusters using wavelet transforms. By combining spectral decomposition with clustering techniques, it helps uncover hidden patterns, periodicities, and dynamic relationships in complex datasets.

🌟 Key Features
Wavelet-Based Feature Extraction: Extracts dynamic frequency and phase information across time-series data (integrating tools like PyBOAT).

Cluster Visualization: Provides intuitive visual representations of temporal and spectral patterns within clusters.

Cluster Evaluation: Assesses cluster quality and coherence across time and frequency domains.

Jupyter Notebook Workflows: Includes interactive notebooks (WAVE_Clust.ipynb) for step-by-step analysis and rapid prototyping.
